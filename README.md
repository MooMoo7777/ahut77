# AHUT77 Web App

This is the AHUT Housing Utility Token web application built with:

- Next.js (Pages Router)
- JavaScript
- Web3Auth Plug & Play
- Sapphire Mainnet
- Ethers.js

## How to Run

```bash
npm install
npm run dev
```

Before logging in, replace `YOUR_WEB3AUTH_CLIENT_ID` in `web3Auth.js` with your Web3Auth client ID,
and `YOUR_AHUT_CONTRACT_ADDRESS` in `tokenService.js` with the deployed AHUT token address.
